# Tic Tac Toe - Android

Aplicación desarrollada para el curso Desarrollo de Aplicaciones
para Dispositivos Móviles de la Universidad Nacional de Colombia.

## Reto 3 - Tic Tac Toe

Juego de tres en línea para Android desarrollado en Java.

### Características

- Juego humano vs. Android.
- Tablero 3x3.
- Detección de victoria y empate.
- Inteligencia básica del computador:
  - realiza una jugada ganadora cuando es posible;
  - bloquea una posible victoria del jugador;
  - realiza una jugada aleatoria en los demás casos.
- Alternancia del jugador que inicia cada partida.
- Registro de victorias, derrotas y empates.
- Reinicio de partida.
- Interfaz gráfica desarrollada con Android Views/XML.

## Tecnologías

- Java
- Android SDK
- XML
- Gradle
- Minimum SDK: API 24
